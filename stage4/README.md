# Stage 4 certification package — `weekly-log`

A multi-step workflow that logs a work week end to end: gather GitHub activity,
enter the hours into Workday, post the TEC status report to Teams. Built in the
`agentic-tools` Claude Code workspace.

| Required artifact | File(s) |
|---|---|
| Workflow definition | `workflow-definition.md` (steps, handoffs, branching, per-agent Stage 3 evidence); code in `../workflow/`, `../.claude/skills/weekly-log/SKILL.md` |
| Guardrails | `guardrails.md`; code in `../workflow/guardrails/`, `../.claude/hooks/require_sentinel.py`, registration in `../.claude/settings.json` |
| Punch-out evidence | `punch-out-evidence.md` (generated by the live bypass test `../workflow/test_bypass.py`) |
| End-to-end success rate | `success-report.md` (generated by `../workflow/report.py` from the audit logs) |
| Audit trail | `audit/<run_id>.jsonl` — one record per step / guardrail / punch-out with model, input/output/cache tokens, cost and duration; `audit/README.md` explains the fields and shows a failure traced to its origin step |

## How to run it

```bash
# unit tests for every deterministic part (177 tests)
python3 -m pytest workflow .claude/skills/*/tests -q

# prompt evals for each agent and for the workflow (real headless Claude turns)
python3 evals/run_skill_eval.py weekly-activity
python3 evals/run_skill_eval.py workday-timelogger
python3 evals/run_skill_eval.py teams-messenger
python3 evals/run_skill_eval.py weekly-log

# the workflow
python3 workflow/run_weekly_log.py --week 2026-09-14..2026-09-18 --hours "Mon 8, Tue 8, Wed 8, Thu 8, Fri 8"
python3 workflow/run_weekly_log.py --test          # next Mon/Tue, 8 h each, Teams self-chat
python3 workflow/run_weekly_log.py --resume <id>   # after creating the sentinel a punch-out asked for

# evidence
python3 workflow/test_bypass.py                    # regenerates punch-out-evidence.md
python3 workflow/report.py --out stage4/success-report.md
python3 workflow/report.py --run <run_id>          # trace one run, name the first failure
```
